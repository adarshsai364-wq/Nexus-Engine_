Nexus-engine: Symbiote Neural Engine & Cosmic Core
The Nexus Neural Engine is an advanced, high-performance WebGL-based interactive web application. It simulates an organic liquid-alloy symbiotic core integrated with a real-time stellar matrix, powered by Three.js and modern frontend design patterns.

🌌 Key Features & Architecture
1. WebGL Stellar Matrix & Galaxy Simulation
Milky Way Particle Field: Renders over 8,000 dynamic particle nodes structured in a spiral galactic arm formation using custom buffer geometries and vertex color interpolation.

Divine Ring Matrix: A secondary orbital constellation of glowing celestial nodes adding depth and organic motion to the void.

Additive Blending: Particle shaders utilize additive blending to simulate intense stellar light emission and depth-of-field fog effects.

2. The Symbiote Core (Artifact Group)
Multi-Layered Alloy Chassis: Features a primary toroidal core surrounded by rotating rings that can transition between multiple material themes:

Obsidian: High-gloss, low-roughness dark metallic finish.

Titanium: Industrial silver-grey alloy texture.

Emerald: Deep organic green crystalline plating.

Quantum: Luminescent cybernetic cyan finish with active glow emission.

Deconstruct Engine (Explosion Physics): Programmatic mesh translation that separates and deconstructs inner structural rings along the z-axis smoothly.

Supernova Pulse Wave: An animated spatial scaling trigger that expands and contracts the entire core artifact with harmonic frequency.

3. Real-Time HUD & Telemetry
Live Performance Monitoring: Automatically calculates and displays real-time FPS (Frames Per Second) and active node counts.

Warp Velocity Control: A smooth interactive range slider that scales the rotational velocity of the entire galaxy and core sub-systems from 0.2x to 4.0x.

Aggressive Surge Mode: A high-alert toggle state that ramps up system speeds by 2.5x, shifting the lighting, system core state (Stable to Rampage), and particle emissions from amber/gold to an aggressive crimson flare.

4. Fluid Dynamics & Pointer Interaction
Parallax Mouse Tracking: The core reacts dynamically to cursor coordinates, creating an organic tilting perspective combined with trigonometric wave oscillations.

Responsive Viewport: Automatically re-centers and recalculates aspect ratios and pixel ratios (up to 2x retina scaling) for optimal rendering performance across devices.
